- **`edgar_read` says why a filing has no financials, and returns an error code for a bad accession number.** On a 10-K with no XBRL, such as Circuit City's FY2008, the `financials` section was a bare `None`; the response now notes that the filing has no XBRL and points to `sections=['Item 8']`, where the statements are (net sales $11,743,691K). A malformed accession number returns `INVALID_ARGUMENTS` with the format hint instead of "Could not find filing".
