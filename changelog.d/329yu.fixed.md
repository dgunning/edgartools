- **`search_filings(start_date=...)` without `end_date` no longer searches every year.** EFTS applies a date range only when it gets both bounds, so a lone start or end date was silently ignored: `search_filings("tariff", forms="10-K", start_date="2025-01-01")` returned 10,000+ hits led by 2010 filings, not 3,841 from 2025-26. A missing bound is now filled in.
