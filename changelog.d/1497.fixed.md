**`search_filings()` returned 0 results for a query EFTS rejected.** EFTS answers a failed query with HTTP 200 and an `errorMessage` body, and that body was read as an empty search: `search_filings("apple", start_date="2024-13-01")` showed 0 hits. Instead it now raises `TransportError` with SEC's message ("Invalid value for MonthOfYear"). `resolve_accession()` no longer turns that body into "no filing". (GH #1497)
