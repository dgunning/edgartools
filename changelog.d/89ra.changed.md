**EdgarTools now requires Python 3.11 or newer.** Python 3.10 reaches end of life on 2026-10-31 and was about 3.8% of downloads over 180 days; the package now declares `Requires-Python: >=3.11`, so `pip install -U edgartools` on 3.10 resolves to the last 5.x release instead of installing 6.0. The pandas floor is unchanged. See docs/upgrade/6.0.md. (GH #938, bead edgartools-89ra)
