- **A note that holds only instant facts renders its own dates.** `render_statement()` and `Statement.to_dataframe()` gave an unclassified note role annual duration columns, so a point-in-time note such as IBM's long-term debt components rendered every cell blank; it now shows the note's instants ($824M and $838M for the unamortized discount). `render_statement(period_filter=...)` is also honoured now.
