- **Sections no longer end on page furniture.** The page number, the "Table of Contents" backlink, the running header of the next page or a footer such as "Apple Inc. | 2024 Form 10-K | 18" sat between a section's last paragraph and the next item's anchor, so `Section.text()` and `.markdown()` carried it; the end now retreats to the last block of content (a table is kept whole, an auditor's date line is kept), which lifts the 10-K truth-set both-exact rate from 86.6% to 89.3%.
