**EntityFacts DataFrames give `fiscal_year`, `is_audited` and `is_estimated` nullable dtypes.** `company.get_facts().query().to_dataframe()` and `EntityFacts.to_dataframe()` now return `Int64` and `boolean`, the same on every query, where 5.x returned `int64`/`bool` but switched to `float64`/`boolean` when no returned row had a value. Use `pd.isna()` to test absence. (bead edgartools-7wtj.1)
