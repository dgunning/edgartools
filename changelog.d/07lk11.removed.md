- **`beautifulsoup4` is no longer installed.** Every parser runs on lxml, so 6.0 drops `beautifulsoup4` and `soupsieve` from the install; no `edgar` module imports bs4. `edgar.xmltools` returns lxml elements only, and passing a BeautifulSoup to `FilingHomepage` or `Attachments.load` (deprecated through 5.x) now raises `TypeError` naming `parse_homepage_html`. See the 6.0 upgrade guide. (GH #931)
