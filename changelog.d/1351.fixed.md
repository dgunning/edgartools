**HTTP 403 and 429 no longer leave a cached empty filing header.** `Filing.sgml()` and `Filing.header` now propagate every status-bearing HTTP error in both error modes, preserving the original 429 `retry_after` value. After an injected refusal, a later successful download on the same filing recovers Apple's `2024-09-28` report period; content-error homepage fallback is unchanged.
