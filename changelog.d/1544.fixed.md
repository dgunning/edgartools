**`search_filings()` dropped every original filing when `forms` listed an amendment code.** EFTS returns amendments only once a code like `S-1/A` is in the list, so `forms=["F-1", "F-1/A"]` found 0 filings where `["F-1"]` found 1. An `X/A` code is now dropped when `X` is listed, since `X` already matches its amendments, and mixing an amendment-only code with other forms warns. (GH #1544)
