**`search_filings()` returned 0 results for a query EFTS rejected.** EFTS answers a failed query with HTTP 200 and an `errorMessage` body, which was read as an empty search: `search_filings("apple", start_date="2024-13-01")` showed 0 hits. A malformed date now raises `InvalidDateError` before any request; any other rejected query raises `TransportError` with SEC's message, also in `resolve_accession()`. `next()` and `fetch_more()` stop at the 10,000-hit window EFTS pages through.
