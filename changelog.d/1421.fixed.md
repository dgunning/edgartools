**`Filing.text()` returned raw `<XBRL>` markup, and `Filing.html()` returned None, when SEC refused a filing's index page.** An inline XBRL primary document that opens with an XML declaration was fetched through the index page instead of read from the submission, which already held it. On NVIDIA's FY2026 10-K (`0001045810-26-000021`), whose index page answers 403, `text()` returned 1,967,829 characters of markup; it now returns the 407,864-character document text. (GH #1421)
