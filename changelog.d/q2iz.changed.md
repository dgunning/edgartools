**Breaking: the HTTP client is now `httpx2`, the maintained fork, instead of the dormant `httpx`.** Unwrapped network errors are `httpx2` classes, so `except httpx.ReadTimeout:` stops catching them; catch `TransportError`. Certificates verify against the OS trust store, not `certifi`, and the logger is `httpx2`. All 263 cassette tests replay unchanged. See the 6.0 upgrade guide. (GH #842, bead edgartools-q2iz)
