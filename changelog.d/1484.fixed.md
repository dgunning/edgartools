**`Document.to_markdown()` wrote headerless tables without a delimiter row, so Markdown parsers did not read them as tables.** The first non-empty row now becomes the header, followed by the `---` row; a table with only one non-empty row, such as a page footer, keeps its plain row. The AbbVie 10-K fixture gains 24 valid tables and no header-only ones. (GH #1484)
