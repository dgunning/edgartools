**`Attachments.download()` works in Jupyter, and `nest-asyncio` is no longer a dependency.** Inside a running event loop the download raised `RuntimeError: This event loop is already running`; a Caterpillar 8-K's 10 attachments now download in a notebook as in a script. Sync wrappers run their coroutines on a private loop in a worker thread instead of patching your loop with the archived `nest-asyncio`.
