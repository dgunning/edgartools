**Hidden spacer cells no longer push table values under the wrong period.** Empty `display:none` cells counted toward a row's width, so JPMorgan's FY2024 10-K reported its 2023 managed-basis overhead ratio (54%) under 2022. They now take no grid slot, which corrects period labels in 220 of 12,948 tables across the HTML test corpus. (GH #1847)
