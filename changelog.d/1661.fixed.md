**`get_current_assets()` and `get_current_liabilities()` returned a narrower company subtotal, or None, instead of the filed current totals.** ADP's FY2026 10-K returned $8.603B ("Total current assets before funds held for clients") against a filed $52.561B, so `current_ratio` read 1.534 instead of 1.051. Both getters now read `us-gaap:AssetsCurrent` / `us-gaap:LiabilitiesCurrent` first, so affected filers see larger, filed values. (GH #1661)
