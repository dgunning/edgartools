**`RenderedStatement.to_dict()` produced output that was not JSON.** The method documents a JSON-safe dict but passed non-finite floats straight through, and `_calculate_comparison()` yields infinity whenever the prior period is a filed zero — ordinary enough that 17 of the corpus's filings hit it. `json.dumps` then wrote a bare `Infinity` token, which no compliant reader accepts, and refused outright under `allow_nan=False`. Non-finite comparison values now serialize as `null`, which carries the same "no bounded comparison" meaning; the filed values in `cells` are untouched. The existing serialization test used the permissive default, which is why it passed. (GH #1290, bead edgartools-hsgs.4)
