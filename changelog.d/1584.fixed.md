**`PortfolioInvestments.from_xbrl` with no `period` could read a date after the report.** The default took the latest instant with an investment fair value, so BlackRock TCP Capital's 10-Q for 2026-03-31 (`0001193125-26-210632`), which tags a roll-forward at fiscal year end, read 2026-12-31: 10 rows and $140,396,441 instead of 331 rows and $1,400,458,176. The default is now the report date when holdings are tagged on it. (GH #1584)
