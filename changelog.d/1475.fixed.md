**`Statement.render()` showed stock par values as zero.** Per-share values under 10 were cut to three decimal places, so the $0.00001 common par value in Apple's FY2023 10-K (`0000320193-23-000106`) displayed `0.00`; the filed precision is now kept. `PreferredStockParOrStatedValuePerShare` was not treated as a per-share value and took the statement scale, so Tesla's $0.001 preferred par displayed `0`. (GH #1475)
