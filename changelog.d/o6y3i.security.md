**XML parsing reads only the document it is given.** Every lxml XML parse, across ownership forms, XBRL, fund reports, 13F, N-PX, ATS-N and Form C, now goes through one parser, `edgar.xmltools.xml_parser`, which never loads an external resource a document names, including DTD parameter entities that libxml2 resolves by default. Entities a document defines itself still expand, so output is unchanged. (edgartools-o6y3i)
