**10-Q `Part I, Item 1` no longer returns the contents page for Donnelley filings whose contents rows carry the item number in a separate cell.** The Donnelley contents parser now reads the item from the row text. Tesla's 10-Q 0000950170-23-033872 returns Part I, Item 1 as 65,181 characters (was the 4,395-character contents page) and Items 3 and 4 are found. (GH #1749)
