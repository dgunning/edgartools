**`show_date_range=True` was ignored by a stitched statement's normal rendering.** The accessor stored the option, but `StitchedStatement.render()` defaulted the parameter to `False` and never read it, so `repr()` showed `Dec 31, 2024` where an explicit `render(show_date_range=True)` showed `Jan 1, 2024 - Dec 31, 2024`. An explicit argument still wins. (GH #1176)
