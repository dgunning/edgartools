**SSL diagnostics and error advice describe the certificates 6.0 actually uses.** `diagnose_ssl()` reported the OS trust store as "not active" and warned about a missing `certifi` bundle, and SSL errors advised `REQUESTS_CA_BUNDLE`, which httpx2 never reads. They now name the source in effect (OS store, `SSL_CERT_FILE` or `SSL_CERT_DIR`), and `get_http_config()` gains a `cert_source` key.
